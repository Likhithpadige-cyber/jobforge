# Noto Sans resume font

Unmodified Noto Sans Regular, version 2.015, ttfautohint v1.8.4.7-5d5b.

(https://github.com/notofonts/latin-greek-cyrillic).
Distributed under SIL Open Font License 1.1, retained in `OFL.txt`.

The binary was obtained from the bundled LibreOffice font distribution.
SHA-256: `f5f552c8c5edb61fe6efb824baf4d4de47b1a8689ab4925ff43f7bd6a4ebece5`.
The regression suite pins this checksum. Updating the font requires a template
version bump and renewed extraction, determinism and visual-layout checks.

The renderer embeds the font and Unicode text map. Unsupported glyphs or
scripts requiring unavailable shaping are refused. This font does not provide
universal Unicode coverage; CJK, emoji and complex-script support are not claimed.
